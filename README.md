# スイムタイマー

水泳部の「50m × N本」のタイム測定を補助するアプリです。
タイムを入力すると、各選手の平均と前の本との差をその場で計算し、終了後は結果表・過去との比較・グラフ・履歴を見られます。

**公開版：** `https://<ユーザー名>.github.io/<リポジトリ名>/`（GitHub Pages）

## 使い方

1. **選手管理**：部員を登録する
2. **新規測定**：日付・距離・本数・参加選手（任意でレーン）を決めて開始
3. **測定入力**：タイムを入力（`3852` → 38.52、`10523` → 1:05.23、休んだ本は `-`）。入力はその場で自動保存
4. **測定終了** → **結果**：結果表と、同じ距離・本数の過去の測定との比較。CSVで保存も可能
5. **グラフ**：選手ごとの1本ずつのタイム推移、複数選手の重ね表示
6. **履歴**：過去の測定の一覧・絞り込み・削除

## データの保存について（大事）

- 入力したデータは **そのブラウザの中だけ** に保存されます。サーバーには送られません。
- 別のPC・別のブラウザ・別のURL（手元の `localhost` と公開版など）では、データは共有されません。
- 部員とデータを共有するときや、PCを替えるときは **「バックアップ」画面** を使います。
  - 入力した人：「書き出す」で JSON ファイルを保存し、LINE などで共有
  - 見る人：「読み込む」でそのファイルを選ぶ（※今そのブラウザにあるデータは置き換わります）
- ブラウザの閲覧データを消すと記録も消えるので、定期的に書き出してください。

## 開発

```bash
npm install
npm run dev     # 開発用サーバー
npm test        # テスト（Vitest）
npm run lint    # コードのチェック（oxlint）
npm run build   # 公開用のファイルを dist/ に作る
```

- 技術構成：Vite + React + TypeScript、Dexie（IndexedDB）、Recharts
- `main` ブランチに push すると、GitHub Actions がテスト・ビルドをして GitHub Pages に公開します（`.github/workflows/deploy.yml`）
